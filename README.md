# Kêr Riek

Site vitrine d’accompagnement Bitcoin pour commerçants, entreprises et particuliers.

**Kêr Riek** est la marque retenue pour le projet. Son sous-titre public
explicite l’activité : « Accepter, utiliser et sécuriser Bitcoin ».

Le nom breton peut évoquer un « lieu souverain » ou un « domaine souverain » :
`kêr` désigne un lieu habité, une cité ou un domaine, tandis que `riek` signifie
« souverain ». Cette identité locale accompagne un service proposé en Bretagne
et à distance partout en France.

## Développement

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```
